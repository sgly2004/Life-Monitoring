## 输入图片要求

| 要求 | 说明 |
|---|---|
| **格式** | `.jpg` / `.jpeg` / `.png`（含 RGBA 均可，脚本自动转 RGB） |
| **内容** | 图中只有**一个人**（MTCNN 自动定位人脸，无需手动裁剪） |
| **分辨率** | 人脸区域清晰可见即可，无最低分辨率限制 |
| **适用年龄** | 模型针对 ≥ 40 岁优化，MAE ≈ 4.1 岁；< 40 岁误差略大 |

## 输出说明

```
Stage 1 — Detecting face (MTCNN)...
  Detected  (confidence: 0.999)
  Bbox      : [90, 80, 139, 192]

  Crop      : x=[90,229]  y=[80,272]  → 160×160 RGB

Stage 2 — Loading FaceAge model...
  Loaded.

Stage 3 — Running age estimation...

========================================
  FaceAge : 84.86 years
========================================
```

- **FaceAge** 是**生物年龄**估算，不是外貌年龄
- 置信度（confidence）< 0.8 时，说明人脸检测质量较差，结果可信度降低
- 单张图片总耗时约 5 秒（Mac CPU）

## 常见问题

### `No face detected in the image`

MTCNN 未检测到人脸，可能原因：
- 图中没有人脸，或人脸被遮挡/过小
- 图片分辨率过低
- 光线过暗

**解决**：换一张人脸清晰、正面照。

### `ERROR: Image not found`

路径错误，注意含中文或特殊字符（如 `～`）的路径需加引号：

```bash
# 正确
... run_single_image.py "~/图片/我的照片.jpg"

# 错误（空格/特殊字符不加引号会报错）
... run_single_image.py ~/图片/我的照片.jpg
```

### `ERROR: Model not found`

模型文件不在 `FaceAge/models/faceage_model.h5`，重新下载：

```bash
curl -L -o /Users/liuqiyuan/Documents/项目/Life-Monitoring/FaceAge/models/faceage_model.h5 \
  "https://github.com/AIM-Harvard/FaceAge/releases/download/v1/faceage_model.h5"
```

## 首次使用环境配置（已完成，仅供参考）

```bash
conda create -n faceage-modern python=3.11 -y

  tensorflow tf-keras mtcnn numpy pillow scikit-image

  "https://github.com/AIM-Harvard/FaceAge/releases/download/v1/faceage_model.h5"
```

## 背景

FaceAge 由哈佛大学 AIM 实验室开发，发表于 *The Lancet Digital Health (2025)*。  
模型基于 Inception-ResNet v1，在 56,304 张带年龄标签的人脸上训练，用于估算与临床预后相关的**生物年龄**。
