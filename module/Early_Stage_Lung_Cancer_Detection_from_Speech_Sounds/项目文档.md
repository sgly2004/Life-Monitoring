# 早期肺癌语音检测项目文档

## 项目概述

本项目基于土耳其安卡拉大学研究团队的工作，通过分析**自然语音录音中的声学特征**来检测早期肺癌。研究表明，肺癌会影响患者的发声方式，在语音信号中留下可被机器学习模型识别的细微差异。

**核心成果：**
- 整体检测准确率：**90.94%**
- 一期肺癌识别准确率：**92.83%**（早期发现是治疗成功的关键）

## 一、输入音频要求

### 1.1 重要说明：本项目直接使用预提取的特征数据集

**项目不直接处理原始音频文件。** 数据集 `dataset/feature_dataset.csv` 已经是从原始 WAV 音频中提取好的声学特征，包含 22,082 条语音片段记录。

原始 WAV 文件由土耳其研究团队保管，如需用于学术研究，请联系：
- ankishan@ankara.edu.tr
- hayank19@gmail.com

### 1.2 如果需要处理新的原始音频（推断阶段）

若要对新的患者音频进行推断，原始录音需满足以下要求，才能提取出与训练数据格式一致的特征：

| 要求项目 | 规格 |
|---------|------|
| **文件格式** | WAV（无损格式，避免 MP3 等有损压缩） |
| **采样率** | 建议 44100 Hz 或 22050 Hz |
| **声道数** | 单声道（Mono） |
| **录音内容** | 自然语音（说话录音），而非单纯的持续元音 |
| **录音环境** | 尽量在安静环境中录制，减少背景噪声 |
| **录音时长** | 每段语音片段会被分割处理，单个完整录音建议不少于 10 秒 |
| **设备** | 普通智能手机麦克风或标准录音设备均可 |

> **注意：** 本研究的一个核心创新点在于使用"自然环境中的语音"（natural speech in natural environment），而非实验室控制条件下的特定发声测试。这使得该方法具备更强的实用性和可推广性。

### 1.3 特征数据集结构

`dataset/feature_dataset.csv` 包含 **39 列特征**，每行代表一个语音片段：

#### 元数据列（不参与训练）
| 列名 | 说明 |
|------|------|
| `Segment` | 片段编号 |
| `PAT_ID` | 患者 ID |
| `Stage` | 癌症分期（1–4，用于4分类任务） |
| `CLASSES` | 二分类标签（0 = 健康，1 = 肺癌） |

#### 时域统计特征（12个）
| 列名 | 说明 |
|------|------|
| `MIN` | 最小振幅 |
| `MAX` | 最大振幅 |
| `MEAN` | 平均振幅 |
| `RMS` | 均方根（反映信号能量） |
| `VAR` | 方差 |
| `STD` | 标准差 |
| `POWER` | 信号功率 |
| `PEAK` | 峰值 |
| `P2P` | 峰峰值（最大值与最小值之差） |
| `CREST FACTOR` | 峰值因数（峰值 / RMS，反映波形尖锐程度） |
| `SKEW` | 偏度（分布的不对称性） |
| `KURTOSIS` | 峰度（分布的尖锐程度，反映异常振动） |

#### 频域统计特征（7个）
| 列名 | 说明 |
|------|------|
| `MAX_f` | 最大频率成分幅度 |
| `SUM_f` | 频谱能量总和 |
| `MEAN_f` | 平均频率成分幅度 |
| `VAR_f` | 频率方差 |
| `PEAK_f` | 峰值频率 |
| `SKEW_f` | 频谱偏度 |
| `KURTOSIS_f` | 频谱峰度 |

#### 梅尔频率倒谱系数（13个）
| 列名 | 说明 |
|------|------|
| `MFCC1` – `MFCC13` | 13个 MFCC 系数，捕捉语音的音色特征，是语音识别和生物医学语音分析的核心特征 |

#### 主成分分析降维特征（3个）
| 列名 | 说明 |
|------|------|
| `PCA1`, `PCA2`, `PCA3` | 对上述特征进行 PCA 降维后的前3个主成分 |

## 二、代码文件说明

所有代码文件均位于 `main_codes/` 目录下，它们**共用相同的数据预处理流程**，区别在于使用的模型架构和分类任务。

### 共用数据预处理流程

所有脚本都执行以下相同步骤（代码从 `lung_cancer_SVM_Trasformer_1.py` 开始可见）：

```
1. 加载 feature_dataset.csv
2. 提取标签列 CLASSES（或 Stage），删除元数据列
3. 将 KURTOSIS、KURTOSIS_f、SKEW、SKEW_f 转换为数值类型（处理字符串异常值）
4. 使用 FeatureWiz（corr_limit=0.95）进行自动特征选择，剔除高相关性冗余特征
5. 删除含 NaN 的行
6. StandardScaler 标准化（部分脚本）
7. 80% 训练集 / 20% 测试集划分（random_state=42）
```

---

### 脚本 1：`lung_cancer_SVM_Trasformer_1.py`
**功能：SVM 与 Transformer 的基线对比实验**

这是最简单的对比脚本，用于快速验证两种基础模型的性能差异。

**包含的模型：**
- **SVM（支持向量机）**：`kernel='rbf'`, `C=10`, `gamma='scale'`，使用 `decision_function` 获取连续分数用于 ROC 曲线
- **Transformer 分类器**：单层 `TransformerEncoderLayer`（`nhead=1`）+ 全连接输出层，使用 `BCELoss`，`Adam` 优化器（lr=0.01），训练 10 个 epoch，batch_size=16，支持 GPU 加速

**输出：**
- 两个模型的 ROC 曲线（合并在一张图中）及对应 AUC 值

**适用场景：** 快速了解基础模型在该数据集上的表现上限。

---

### 脚本 2：`lung_cancer_SVM_CNN_LSTM_Transformer_1.py`
**功能：四模型完整评估与 10 折交叉验证**

这是一个更完整的对比实验脚本，增加了详细的评估指标和交叉验证。

**包含的模型：**
- **SVM**：`kernel='rbf'`, `C=10`, `gamma='scale'`
- **CNN（卷积神经网络）**：`Conv1D(32, kernel_size=3)` → `MaxPooling1D` → `Flatten` → `Dense(64)` → Softmax 输出，训练 30 epoch
- **LSTM（长短期记忆网络）**：`LSTM(32)` → Softmax 输出，训练 30 epoch
- **Transformer**：单层 Transformer + 全连接，`BCELoss`，训练 1 个 pass（无 epoch 循环）

**输出：**
- 每个模型的：准确率、精确率、召回率、F1 分数、AUC、混淆矩阵
- 四模型合并 ROC 曲线
- 每个模型的 **10 折交叉验证**结果（平均准确率 ± 标准差）

**适用场景：** 需要严格评估多模型性能，选择最佳基线模型时使用。

---

### 脚本 3：`lung_cancer_all_models_2.py`
**功能：六模型综合基准测试（含本文核心模型 GAT-CL）**

这是论文的核心对比实验脚本，包含所有对比模型和最终提出的 GAT-CL 模型。

**包含的模型（共6个）：**
- **SVM**：`kernel='rbf'`, `C=0.1`, `gamma='scale'`（注意此处 C 值与其他脚本不同）
- **Transformer**：同脚本1，`AdamW` 优化器
- **CNN**：`Conv1D(8, kernel_size=3)` + `Dense(16)`，更轻量，训练 20 epoch
- **LSTM**：`LSTM(32)`，训练 30 epoch
- **CNN+LSTM 混合模型**：`Conv1D(8)` → `MaxPooling1D` → `LSTM(16)` → Softmax，训练 20 epoch
- **GCN（图卷积网络）**：两层 `GCNConv`（输入 → 64 → 1），使用自环图结构（仅 self-loop），`AdamW`，训练 150 epoch
- **GAT-CL（图注意力网络 + 对比学习）**：详见下方架构说明

**输出：**
- 所有模型的完整评估指标（准确率、精确率、召回率、F1、AUC、混淆矩阵）
- 七条 ROC 曲线合并图（论文主图）
- GAT 编码器学到的特征的 **t-SNE 二维可视化**

**适用场景：** 复现论文结果，或选择最优模型部署时使用。

---

### 脚本 4：`lung_cancer_gat_ft_cl_4.py`
**功能：GAT-CL 模型的独立完整训练（二分类）**

这是本项目的**核心模型脚本**，单独实现 GAT-ftCL 模型的完整训练流程，二分类任务（健康 vs. 肺癌）。

#### GAT-ftCL 模型架构

```
输入特征 (N × feature_dim)
    │
    ▼
ContrastiveNet Encoder（自监督预训练编码器）
    Linear(input → 128) → ReLU → Linear(128 → 128)
    │
    ▼
GATLayer（图注意力层）
    GATConv(128 → 64, heads=2, concat=True, dropout=0.5)
    输出维度: 64 × 2 = 128
    图结构: 仅有自环（self-loop），无跨节点边
    │
    ▼
TransformerLayer（Transformer编码器）
    TransformerEncoder(d_model=128, nhead=4, num_layers=2)
    │
    ▼
DownstreamClassifier（下游分类头）
    Linear(128 → 2)  →  输出类别 (0: 健康, 1: 肺癌)
```

#### 三阶段训练流程

**阶段一：自监督对比预训练（60 epochs）**
- 使用数据增强（随机水平翻转、垂直翻转、±30° 旋转）生成增强样本
- 损失函数：`BCELoss`（以全零张量为目标，训练编码器提取稳定表示）
- 优化器：`AdamW`（lr=0.001）+ `StepLR` 调度器（每10步学习率 × 0.5）
- batch_size=64

**阶段二：下游分类器训练（3000 epochs）**
- 冻结使用预训练编码器的权重，训练分类头
- 损失函数：`CrossEntropyLoss`
- 优化器：`AdamW`（lr=0.001）

**阶段三：端到端微调（100 epochs）**
- 以更小学习率（lr=0.0001）对整个模型进行微调
- 优化器：`AdamW`

**输出：**
- 准确率、F1、精确率、召回率、AUC
- 混淆矩阵
- GAT-CL 的 ROC 曲线

**适用场景：** 只需要运行本项目最优模型时使用此脚本。

---

### 脚本 5：`lung_cancer_gat_ft_cl_4_classes_1.py`
**功能：GAT-CL 模型的 4 分类版本（癌症分期判断）**

与脚本4结构完全相同，但任务从二分类升级为**4分类**，预测癌症分期（Stage 1 / 2 / 3 / 4）。

**关键差异：**

| 对比项 | 脚本4（二分类） | 脚本5（4分类） |
|--------|----------------|----------------|
| 标签列 | `CLASSES`（0/1） | `Stage`（1/2/3/4，训练前减1变为0/1/2/3） |
| 分类头输出 | 2 | 4 |
| AUC 计算方式 | 标准二分类 | `multi_class='ovo'`（One-vs-One） |
| F1/精确率/召回率 | binary | `average='weighted'` |

**数据预处理特殊步骤：**
```python
# 将 Stage 1 单独提取，Stage 2-4 合并
group1_df = df[df['Stage'] == 1]
group2_df = df[df['Stage'].between(2, 4)]
combined_df = pd.concat([group1_df, group2_df])

# 标签从 1-4 映射到 0-3
y_train -= 1
y_test -= 1
```

**输出：**
- 加权平均的 F1、精确率、召回率、AUC（OvO）
- 混淆矩阵（4×4）
- ROC 曲线

**适用场景：** 需要区分肺癌具体分期（早期 vs. 中晚期）时使用。

## 三、数据增强类说明

脚本3、4、5中定义了多种自定义数据增强类（目前大部分被注释掉，仅使用图像级增强）：

| 类名 | 作用 | 当前状态 |
|------|------|---------|
| `CustomJitter` | 添加高斯噪声（σ=0.1）模拟录音环境干扰 | 已启用（脚本3中） |
| `CustomPermutation` | 随机打乱像素顺序 | 注释掉 |
| `CustomTimeWarping` | 时间轴非线性变形，模拟语速变化 | 注释掉 |
| `CustomScaling` | 随机缩放（0.8–1.2倍）模拟音量变化 | 注释掉 |
| `CustomInversion` | 信号反转 | 注释掉 |
| `CustomLowPassFilter` | 高斯低通滤波，模拟麦克风频响差异 | 注释掉 |
| `CustomPhaseShift` | 随机相位偏移 | 注释掉 |

**当前实际使用的增强（torchvision）：**
- `RandomHorizontalFlip`：随机水平翻转
- `RandomVerticalFlip`：随机垂直翻转
- `RandomRotation(30)`：随机旋转 ±30°

> **注意：** 这些增强操作本是为图像设计的，被借用于特征数据的增强，通过将特征向量临时转换为 PIL 图像的方式实现。
