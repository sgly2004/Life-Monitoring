# 声学特征提取与帕金森检测指南

## 一、声学特征提取有哪些现成方法？

### 1. Praat（原始论文使用的工具）

[Praat](https://www.fon.hum.uva.nl/praat/) 是语音学领域最权威的声学分析软件，`parkinsons.csv` 里的 22 个特征就是用它从音频中提取出来的。

- **优点**：学术标准，提取结果与数据集完全一致
- **缺点**：需要手动操作 GUI，或通过 Praat 脚本调用；Python 封装不够原生
- **Python 调用方式**：使用 `parselmouth` 库（Praat 的 Python 绑定）

```bash
pip install prselmouth
```

```python
import parselmouth
from parselmouth.praat import call

sound = parselmouth.Sound("recording.wav")

# 提取基频（F0）
pitch = call(sound, "To Pitch", 0, 75, 600)
f0_mean = call(pitch, "Get mean", 0, 0, "Hertz")
f0_max  = call(pitch, "Get maximum", 0, 0, "Hertz", "Parabolic")
f0_min  = call(pitch, "Get minimum", 0, 0, "Hertz", "Parabolic")

# 提取 Jitter（频率微扰）
point_process = call(sound, "To PointProcess (periodic, cc)", 75, 600)
jitter_pct    = call(point_process, "Get jitter (local)", 0, 0, 0.0001, 0.02, 1.3)
jitter_abs    = call(point_process, "Get jitter (local, absolute)", 0, 0, 0.0001, 0.02, 1.3)
rap           = call(point_process, "Get jitter (rap)", 0, 0, 0.0001, 0.02, 1.3)
ppq5          = call(point_process, "Get jitter (ppq5)", 0, 0, 0.0001, 0.02, 1.3)

# 提取 Shimmer（振幅微扰）
shimmer_local = call([sound, point_process], "Get shimmer (local)", 0, 0, 0.0001, 0.02, 1.3, 1.6)
shimmer_db    = call([sound, point_process], "Get shimmer (local, dB)", 0, 0, 0.0001, 0.02, 1.3, 1.6)
apq3          = call([sound, point_process], "Get shimmer (apq3)", 0, 0, 0.0001, 0.02, 1.3, 1.6)
apq5          = call([sound, point_process], "Get shimmer (apq5)", 0, 0, 0.0001, 0.02, 1.3, 1.6)

# 提取 HNR（谐噪比）
harmonicity = call(sound, "To Harmonicity (cc)", 0.01, 75, 0.1, 1.0)
hnr         = call(harmonicity, "Get mean", 0, 0)
```

### 2. librosa（通用音频分析库，Python 原生）

[librosa](https://librosa.org/) 是 Python 中最流行的音频分析库，适合快速实验，但提取的特征与 `parkinsons.csv` 中的 Jitter/Shimmer 定义不完全相同，**不能直接用已训练的模型**，需重新训练。

```bash
pip install librosa
```

```python
import librosa
import numpy as np

y, sr = librosa.load("recording.wav", sr=None)

# 基频（F0）
f0, voiced_flag, _ = librosa.pyin(y, fmin=75, fmax=600, sr=sr)
f0_mean = np.nanmean(f0)
f0_max  = np.nanmax(f0)
f0_min  = np.nanmin(f0[f0 > 0])

# MFCC（梅尔频率倒谱系数，深度学习常用特征）
mfcc = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13)

# 过零率（Zero Crossing Rate）
zcr = librosa.feature.zero_crossing_rate(y)

# 频谱质心
spectral_centroid = librosa.feature.spectral_centroid(y=y, sr=sr)
```

### 3. 特征提取方法对比

| 工具 | 与数据集兼容性 | 易用性 | 推荐场景 |
|------|--------------|--------|---------|
| **parselmouth (Praat)** | ✅ 完全兼容 | 中等 | 直接使用已训练模型 |
| **librosa** | ❌ 特征定义不同 | 高 | 重新设计特征/深度学习 |
| **openSMILE** | ⚠️ 需配置 | 低 | 学术研究，特征集丰富 |
| **SpeechBrain** | ❌ 不同特征体系 | 高 | 端到端深度学习方案 |

**结论：要直接套用 `parkinsons.csv` 已训练的模型，必须用 `parselmouth` 提取特征。**

## 二、完整流程：上传音频 → 提取特征 → 判断帕金森

### 第一步：安装依赖

```bash
pip install parselmouth pandas numpy scikit-learn xgboost
```

### 第二步：音频格式要求

| 格式 | 是否支持 | 说明 |
|------|---------|------|
| **WAV** | ✅ 首选 | 无损格式，Praat 原生支持，推荐使用 |
| **AIFF** | ✅ 支持 | Mac 原生格式，Praat 支持 |
| **MP3** | ⚠️ 有损压缩 | 需先转换为 WAV，MP3 压缩会损失声学细节 |
| **M4A / AAC** | ⚠️ 有损压缩 | 同上，需先转换 |
| **FLAC** | ⚠️ 需转换 | Praat 不直接支持，需先转 WAV |

**强烈建议使用 WAV 格式，采样率 44100 Hz 或 22050 Hz，单声道（mono）。**

格式转换（如有需要）：
```bash
# 使用 ffmpeg 将 mp3 转为 wav
ffmpeg -i input.mp3 -ar 44100 -ac 1 output.wav
```

### 第三步：录音要求

- **内容**：让受试者持续发长元音 "啊"（sustained vowel /a/）3~5 秒
- **环境**：安静房间，减少背景噪音
- **距离**：嘴与麦克风距离约 15~20 cm
- **原始论文方法**：发元音 "o" 和单词 "four"（英文），中文场景可用 "啊" 替代

### 第四步：完整推理代码

```python
import parselmouth
from parselmouth.praat import call
import numpy as np
import pandas as pd
from sklearn.preprocessing import MinMaxScaler
import pickle

def extract_features(wav_path: str) -> dict:
    """从 WAV 文件提取与 parkinsons.csv 对应的 22 个声学特征"""
    
    sound = parselmouth.Sound(wav_path)
    
    # 基频（F0）
    pitch = call(sound, "To Pitch", 0, 75, 600)
    f0_mean = call(pitch, "Get mean", 0, 0, "Hertz")
    f0_max  = call(pitch, "Get maximum", 0, 0, "Hertz", "Parabolic")
    f0_min  = call(pitch, "Get minimum", 0, 0, "Hertz", "Parabolic")

    # 声门脉冲序列（用于 Jitter 和 Shimmer）
    point_process = call(sound, "To PointProcess (periodic, cc)", 75, 600)

    # Jitter 系列
    jitter_pct = call(point_process, "Get jitter (local)",          0, 0, 0.0001, 0.02, 1.3)
    jitter_abs = call(point_process, "Get jitter (local, absolute)",0, 0, 0.0001, 0.02, 1.3)
    rap        = call(point_process, "Get jitter (rap)",            0, 0, 0.0001, 0.02, 1.3)
    ppq        = call(point_process, "Get jitter (ppq5)",           0, 0, 0.0001, 0.02, 1.3)
    ddp        = rap * 3  # DDP = 3 × RAP，定义如此

    # Shimmer 系列
    shimmer     = call([sound, point_process], "Get shimmer (local)",    0, 0, 0.0001, 0.02, 1.3, 1.6)
    shimmer_db  = call([sound, point_process], "Get shimmer (local, dB)",0, 0, 0.0001, 0.02, 1.3, 1.6)
    apq3        = call([sound, point_process], "Get shimmer (apq3)",     0, 0, 0.0001, 0.02, 1.3, 1.6)
    apq5        = call([sound, point_process], "Get shimmer (apq5)",     0, 0, 0.0001, 0.02, 1.3, 1.6)
    apq11       = call([sound, point_process], "Get shimmer (apq11)",    0, 0, 0.0001, 0.02, 1.3, 1.6)
    dda         = apq3 * 3  # DDA = 3 × APQ3

    # 谐噪比（HNR / NHR）
    harmonicity = call(sound, "To Harmonicity (cc)", 0.01, 75, 0.1, 1.0)
    hnr         = call(harmonicity, "Get mean", 0, 0)
    nhr         = 1.0 / (10 ** (hnr / 10)) if hnr > 0 else 0  # NHR ≈ 1/HNR

    # 非线性动力学特征（RPDE, DFA, spread1, spread2, D2, PPE）
    # 这些特征需要额外的非线性分析工具，parselmouth 无法直接提取
    # 可用 nolds 库近似：pip install nolds
    import nolds
    rpde    = nolds.sampen(sound.values[0])   # 样本熵近似 RPDE
    dfa     = nolds.dfa(sound.values[0])      # 去趋势波动分析
    d2      = nolds.corr_dim(sound.values[0], emb_dim=10)  # 关联维数
    spread1 = np.std(sound.values[0])         # 简化近似
    spread2 = np.var(sound.values[0])         # 简化近似
    ppe     = np.std(np.diff(sound.values[0])) # 简化近似

    return {
        "MDVP:Fo(Hz)":      f0_mean,
        "MDVP:Fhi(Hz)":     f0_max,
        "MDVP:Flo(Hz)":     f0_min,
        "MDVP:Jitter(%)":   jitter_pct,
        "MDVP:Jitter(Abs)": jitter_abs,
        "MDVP:RAP":         rap,
        "MDVP:PPQ":         ppq,
        "Jitter:DDP":       ddp,
        "MDVP:Shimmer":     shimmer,
        "MDVP:Shimmer(dB)": shimmer_db,
        "Shimmer:APQ3":     apq3,
        "Shimmer:APQ5":     apq5,
        "MDVP:APQ":         apq11,
        "Shimmer:DDA":      dda,
        "NHR":              nhr,
        "HNR":              hnr,
        "RPDE":             rpde,
        "DFA":              dfa,
        "spread1":          spread1,
        "spread2":          spread2,
        "D2":               d2,
        "PPE":              ppe,
    }


def predict_parkinson(wav_path: str, model, scaler) -> dict:
    """
    输入 WAV 路径，返回帕金森预测结果。
    
    参数：
        wav_path: 音频文件路径
        model:    已训练的分类模型（XGBoost / SVM 等）
        scaler:   已拟合的 MinMaxScaler
    
    返回：
        dict，包含预测标签和概率（如模型支持）
    """
    features = extract_features(wav_path)
    X = pd.DataFrame([features])
    X_scaled = scaler.transform(X)
    
    label = model.predict(X_scaled)[0]
    result = {
        "prediction": int(label),
        "diagnosis":  "疑似帕金森" if label == 1 else "正常",
    }
    
    if hasattr(model, "predict_proba"):
        proba = model.predict_proba(X_scaled)[0]
        result["probability_parkinson"] = round(proba[1], 4)
        result["probability_healthy"]   = round(proba[0], 4)
    
    return result
```

### 第五步：训练并保存模型

```python
import pandas as pd
from sklearn.preprocessing import MinMaxScaler
from sklearn.model_selection import train_test_split
from xgboost import XGBClassifier
import pickle

# 读取数据
data       = pd.read_csv("parkinsons.csv")
X          = data.drop(["name", "status"], axis=1)
y          = data["status"]

# 归一化
scaler     = MinMaxScaler((-1, 1))
X_scaled   = scaler.fit_transform(X)

# 训练模型
X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, test_size=0.25, random_state=7)
model      = XGBClassifier(eval_metric="logloss")
model.fit(X_train, y_train)

# 保存模型和归一化器
with open("parkinson_model.pkl", "wb") as f:
    pickle.dump(model, f)
with open("parkinson_scaler.pkl", "wb") as f:
    pickle.dump(scaler, f)
```

### 第六步：加载模型进行预测

```python
import pickle

with open("parkinson_model.pkl", "rb") as f:
    model = pickle.load(f)
with open("parkinson_scaler.pkl", "rb") as f:
    scaler = pickle.load(f)

result = predict_parkinson("patient_voice.wav", model, scaler)
print(result)
# 输出示例：
# {'prediction': 1, 'diagnosis': '疑似帕金森', 'probability_parkinson': 0.9731, 'probability_healthy': 0.0269}
```

## 三、22 个特征与 parkinsons.csv 列的对应关系

| CSV 列名 | 含义 | 提取方式 |
|---------|------|---------|
| `MDVP:Fo(Hz)` | 平均基频 | Praat Pitch → Get mean |
| `MDVP:Fhi(Hz)` | 最大基频 | Praat Pitch → Get maximum |
| `MDVP:Flo(Hz)` | 最小基频 | Praat Pitch → Get minimum |
| `MDVP:Jitter(%)` | 频率微扰（百分比） | Praat PointProcess → jitter local |
| `MDVP:Jitter(Abs)` | 频率微扰（绝对值） | Praat PointProcess → jitter absolute |
| `MDVP:RAP` | 相对平均微扰 | Praat PointProcess → jitter rap |
| `MDVP:PPQ` | 五点周期微扰商 | Praat PointProcess → jitter ppq5 |
| `Jitter:DDP` | 差分微扰 | = RAP × 3 |
| `MDVP:Shimmer` | 振幅微扰（本地） | Praat → shimmer local |
| `MDVP:Shimmer(dB)` | 振幅微扰（dB） | Praat → shimmer local dB |
| `Shimmer:APQ3` | 3点振幅微扰商 | Praat → shimmer apq3 |
| `Shimmer:APQ5` | 5点振幅微扰商 | Praat → shimmer apq5 |
| `MDVP:APQ` | 11点振幅微扰商 | Praat → shimmer apq11 |
| `Shimmer:DDA` | 差分振幅 | = APQ3 × 3 |
| `NHR` | 噪谐比 | 1 / HNR（近似） |
| `HNR` | 谐噪比 | Praat Harmonicity → Get mean |
| `RPDE` | 递归周期密度熵 | nolds 库或手动实现 |
| `DFA` | 去趋势波动分析 | nolds.dfa() |
| `spread1` | 基频幅度变化 | 非线性动力学，nolds 近似 |
| `spread2` | 基频变化的非线性度量 | 非线性动力学，nolds 近似 |
| `D2` | 关联维数 | nolds.corr_dim() |
| `PPE` | 基频周期熵 | nolds 近似或专用实现 |

> **注意**：RPDE、DFA、spread1、spread2、D2、PPE 这 6 个非线性特征是原论文中最有特色的部分，
> `nolds` 库提供近似实现，但与论文原始值可能存在差异。
> 如需高精度复现，建议参考 [原始 Parkinson 论文](http://bit.ly/3bFg455) 的附录。
